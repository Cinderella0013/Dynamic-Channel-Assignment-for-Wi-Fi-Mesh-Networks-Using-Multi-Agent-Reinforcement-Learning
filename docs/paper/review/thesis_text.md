Reinforcement Learning.  Project in Information Technology I.  Bachelor of Science in Information 
 
Technology,  College of Computing,  Khon Kaen University. 
Project Advisor:  Prof.  Chakchai So-In,  Ph.D. 
ABSTRACT 
This project studies joint dynamic channel assignment and routing in multi-hop Wi-Fi mesh 
networks. We propose EGAT-MAPPO, in which every node is an agent that chooses its downlink channel 
and its parent. The model combines an edge-aware graph attention encoder (GATv2), GRU memory, two 
decision timescales and a residual prior from Ko's local-cost rule. It is warm-started by behaviour cloning 
from Ko, trained with MAPPO, and executed in a decentralised way with switch hysteresis that suppresses 
unnecessary switches. 
We evaluate it in a custom Python simulator with an 802.11ax PHY and ns-3 default path loss: 20 
nodes, two gateways and six downlink channels, across 11 scenarios. The baselines are a static assignment 
(M0), Ko, Q-neutral, Yuan (GAT+DQN) and Li (GAT-A2C). Every learned method is trained with five seeds 
and tested on 20 topologies per scenario. We use a pre-registered five-metric composite and intervals that 
count the training-seed variance of both methods. 
EGAT-MAPPO improves on every baseline in its published form by at least 10%, significantly: Ko 
+19.5%, Li +16.0% and Yuan +25.6%. It meets all four pre-registered criteria. On fresh topologies never 
used for any decision, it improves on Ko by 15.1% and loses no scenario to Ko. Most of the gain over Ko 
comes from fewer switches (43 versus 580 per episode). When Li and Yuan receive the same hysteresis, 
the margin falls to 4-8%, and against Li with hysteresis it is not significant on fresh topologies. The results 
are not yet validated in ns-3, and with queue-preserving switches the model still loses to Ko on an unseen 
grid topology. 
Keywords:  Channel assignment,  Routing,  Wi-Fi mesh,  Graph attention network,  MAPPO,  Multi-
agent reinforcement learning

2.1  ทฤษฎีที่เกี่ยวข้อง 
 2.1.1  Wi-Fi Mesh Networks (เครือข่ายตาข่าย Wi-Fi) 
         เครือข่ายตาข่ายไร้สาย (Wireless Mesh Network:  WMN) คือโครงสร้างเครือข่ายที่ประกอบด้วยจุดเชื่อมต่อ 
(Access Points:  APs) หรือโหนดหลายตัวเชื่อมต่อกันแบบ peer-to-peer โดยแต่ละโหนดสามารถทำหน้าที่ทั้งรับ ส่ง 
และกระจายข้อมูลไปยังโหนดอื่น ๆ ได้ ทำให้เครือข่ายมีความทนทานสูง (self-healing) และสามารถ reroute ได้เมื่อ
โหนดใดโหนดหนึ่งล้มเหลว ข้อดีของเครือข่ายชนิดนี้คือสามารถครอบคลุมพื้นที่ขนาดใหญ่ได้โดยไม่จำเป็นต้องเดินสาย
ทั้งหมด แต่ก็มีข้อจำกัดคือความซับซ้อนในการจัดการช่องสัญญาณ การควบคุม topology และปัญหาความหน่วง 
(latency) ที่เพิ่มขึ้นเมื่อจำนวน hop มากขึ้น [1] 
 2.1.2  Dynamic Channel Assignment (การจัดสรรช่องสัญญาณแบบไดนามิก) 
          Dynamic Channel Assignment (DCA) หรือ Dynamic Channel Allocation คือกลไกที่ไม่ได้จอง
ช่องสัญญาณไว้ล่วงหน้าให้แต่ละโหนด (เช่น สถานีฐานในเครือข่ายเซลลูลาร์หรือ Wireless LAN) แต่จะจัดสรรช่องแบบ 
ไดนามิก ตามความต้องการ ณ ขณะนั้น เมื่อมีการร้องขอการใช้งาน เช่นวางการสื่อสาร หรือมีการเปลี่ยนแปลงของทราฟ
ฟิกหรือสภาพแวดล้อมระบบ ไดนามิกแชแนลแอสไซน์เมนต์จะเลือกช่องสัญญาณที่เหมาะสมที่สุดตามอัลกอริทึมที่
ประเมินตัวแปรต่าง ๆ เช่นอะไรที่จะลด interference,  blocking probability, และปรับ frequency reuse ให้
อัตโนมัติ ประหยัดทรัพยากรความถี่ และรองรับความเปลี่ยนแปลงของทราฟฟิกได้ดีกว่า Fixed Channel Allocation 
ที่จองช่องแบบถาวรใน [2] 
 2.1.3  Multi-Agent Reinforcement Learning (MARL) 
                MARL เป็นการต่อยอดจาก Reinforcement Learning (RL) ที่มีหลาย agent เรียนรู้ร่วมกันใน environment 
เดียวกัน แต่ละ agent เลือก action ตาม policy และรับ reward จาก action นั้น จึงประสานการตัดสินใจได้โดย 
ไม่ต้องใช้ศูนย์กลาง แนวคิดนี้เหมาะกับ Wi-Fi Mesh ที่มี node กระจายหลายจุด [3] 
 2.1.4  Channel Interference (CI) 
การชนกันของช่องสัญญาณเกิดขึ้นเมื่ออุปกรณ์ไร้สายหลายตัวใช้ช่องความถี่เดียวกันหรือใกล้กันมากเกินไป ส่งผล
ให้เกิดการรบกวนที่ลด Throughput เพิ่ม Latency และทำให้ Packet Loss สูงขึ้น สาเหตุหลักมาจากการกำหนด
ช่องสัญญาณแบบคงที่ การมีโหนดหนาแน่นในพื้นที่จำกัด และการรบกวนจากอุปกรณ์อื่น การแก้ปัญหานี้ต้องใช้วิธีจัดสรร
ช่องสัญญาณแบบไดนามิกที่สามารถปรับตามสภาพแวดล้อมแบบเรียลไทม์ [4]

 2.1.5  การเรียนรู้แบบเสริมกำลัง (Reinforcement Learning - RL) และ Q-Learning 
         Reinforcement Learning (RL) ให้ Agent เรียนรู้การตัดสินใจจากการโต้ตอบกับ Environment เพื่อเพิ่ม 
cumulative Reward งานนี้ประยุกต์ใช้ Q-Learning แบบ Value-based กับ Access Point โดยให้แต่ละ node 
เรียนรู้ Q-value ของแต่ละ Action ในแต่ละ State เมื่อ action เพิ่ม Throughput จะได้ reward เชิงบวก;  เมื่อเกิด 
Interference จะได้รับ penalty การลองผิดลองถูกทำให้ node ปรับน ้ำหนักเครือข่ายและสร้าง Policy สำหรับ 
channel assignment ได้เอง [5] 
 2.1.6  โครงข่ายประสาทแบบกราฟ (Graph Neural Networks - GNN) 
         โครงข่ายประสาทแบบกราฟ (Graph Neural Networks หรือ GNN) เป็นสถาปัตยกรรมการเรียนรู้เชิงลึกที่
ออกแบบมาเพื่อประมวลผลข้อมูลที่มีโครงสร้างความสัมพันธ์แบบกราฟ ซึ่งประกอบด้วยโหนด (Node) และเส้นเชื่อม 
(Edge) สำหรับโครงงานนี้ โครงสร้างของเครือข่าย Wi-Fi Mesh จะถูกแปลงเป็นกราฟโดยให้จุดเชื่อมต่อเป็นโหนด และ
ระยะการรบกวนของสัญญาณเป็นเส้นเชื่อม GNN จะนำมาใช้เพื่อแก้ข้อจำกัดด้านการรับรู้ข้อมูลที่ไม่สมบูรณ์ (Partial 
Observability) ในระบบหลายตัวแทน ผ่านกลไกการส่งผ่านข้อความ (Message Passing) ที่เปิดโอกาสให้แต่ละโหนด
สามารถดึงข้อมูลสถานะจากเพื่อนบ้านข้างเคียงมาประมวลผลรวมกับข้อมูลของตนเองได้ การสกัดคุณลักษณะเชิงพื้นที่ 
(Spatial Feature Extraction) เช่นนี้ ทำให้ตัวแทนมีความตระหนักรู้ถึงโครงสร้างของเครือข่าย (Topology 
Awareness) อย่างลึกซึ้ง ซึ่งช่วยแก้ปัญหาพฤติกรรมการแห่ตามกัน (Herd Behavior) และทำให้ระบบสามารถตัดสินใจ
หลบหลีกการชนกันของคลื่นความถี่ได้อย่างแม่นยำยิ่งขึ้น[6] 
2.1.7  Graph Attention Network รุ่น GATv2 และคุณลักษณะของขอบ 
Graph Attention Network (GAT) [21] ให้แต่ละโหนดรวมข้อมูลจากเพื่อนบ้านด้วยน ้ำหนักความสนใจที่เรียนได้ 
GATv2 [22] แก้ข้อจำกัดของ GAT เดิมที่ลำดับความสำคัญของเพื่อนบ้านไม่ขึ้นกับโหนดผู้ถาม โดยใส่ฟังก์ชันไม่เชิงเส้นก่อน
คูณกับเวกเตอร์ความสนใจ ในเครือข่ายไร้สาย ความสัมพันธ์ระหว่างโหนดขึ้นกับลิงก์ เช่น SNR อัตราส่งข้อมูล และภาระของ
ลิงก์ โครงงานนี้จึงเพิ่มคุณลักษณะของขอบเข้าไปในคะแนนความสนใจ 
2.1.8  Proximal Policy Optimization และ MAPPO 
Proximal Policy Optimization (PPO) [23] เป็นวิธี policy gradient ที่จำกัดขนาดการปรับนโยบายในแต่ละรอบ
ด้วยการตัด (clip) อัตราส่วนความน่าจะเป็น ทำให้การฝึกเสถียร และมักใช้ร่วมกับ Generalized Advantage Estimation 
(GAE) [24] MAPPO [25] ขยาย PPO ไปสู่หลายตัวแทนแบบ centralized training with decentralized execution โดย
ให้ตัวแทนใช้ actor ร่วมกัน และใช้ critic ที่เห็นข้อมูลภาพรวมเฉพาะตอนฝึก งานของ Yu และคณะ [25] แสดงว่า MAPPO 
ทำได้ดีในเกมร่วมมือหลายแบบ

QLBT สามารถ ทำงานเหนือกว่า CSMA/CA แบบเดิมในสถานการณ์ต่างๆ ทั้งความหนาแน่นทราฟฟิกสูง ต ่ำ และงานที่
ไวต่อเวลา และยังทำงานได้ทนทานต่อการเปลี่ยนแปลงสภาพแวดล้อม และสามารถทำงานร่วมกับอุปกรณ์ CSMA/CA 
แบบเดิมได้ด้วย ข้อจำกัดของงานนี้คือเป็นงานวิจัยทางทฤษฎีที่ทดสอบในซิมูเลชัน การนำไปใช้จริงยังต้องพิจารณาด้าน

โดยเน้นวัตถุประสงค์หลายตัวคือ ลดค่า End-to-End Delay และเพิ่มประสิทธิภาพการใช้ช่องสัญญาณ (channel 
efficiency) ออกแบบเป็น CTDE (central critic,  distributed actors) โดยตัวประมาณค่า centralized critic มี
ข้อมูลเครือข่ายทั้งหมด ในขณะที่แต่ละตัวกระทำเรียนรู้แบบอิสระ ผลการทดสอบใน QaulNet (จำลองเครือข่ายจริง) ผล
ชี้ว่าระบบ MACRL นี้ช่วยลด latency และเพิ่มสัดส่วนช่องว่าง (idle channel) ได้ดีกว่าวิธีอื่นๆ แม้ว่าจะต้องปรับสมดุล

ประเด็นเช่น overhead หรือ scalability เมื่อจำนวนตัวแทนเพิ่มขึ้นมากๆ  [11]

2.2.8  GAT-based MARL for Slicing Resource Management 
    งานวิจัยนี้นำโครงข่ายประสาทแบบกราฟเชิงความสนใจ (Graph Attention Network:  GAT) มาวางไว้ที่ส่วนรับ
ข้อมูลของอัลกอริทึม DQN และ A2C เพื่อเสริมความร่วมมือเชิงพื้นที่และเวลาระหว่างสถานีฐานในเครือข่ายเซลลูลาร์
หนาแน่น โดยแต่ละสถานีฐานทำหน้าที่เป็นตัวแทนหนึ่งตัว จุดเด่นคือการพิสูจน์ว่ากลไก GAT สามารถยกระดับประสิทธิภาพ
ของการเรียนรู้แบบเสริมกำลังเชิงลึกได้ในลักษณะทั่วไป กล่าวคือใช้ได้ทั้งกับอัลกอริทึมประเภทประเมินมูลค่า (Value-based) 
และประเภทผู้กระทำ-ผู้วิจารณ์ (Actor-critic) ผลการทดลองรายงานว่าที่ระดับความละเอียดหยาบ GAT-DQN ให้
ผลตอบแทนระบบสูงกว่า DQN เดิมร้อยละ 4 และ GAT-A2C สูงกว่า A2C เดิมร้อยละ 5 ส่วนที่ระดับความละเอียดสูงซึ่งมี
ปริภูมิการกระทำใหญ่ขึ้น ทั้งสองอัลกอริทึมให้ผลดีขึ้นร้อยละ 7 และยังมีการศึกษาแบบตัดองค์ประกอบ (Ablation Study) 
ยืนยันว่า GAT ช่วยเพิ่มประสิทธิภาพการใช้คลื่นความถี่โดยไม่ลดอัตราความสำเร็จตามข้อตกลงระดับบริการ ข้อจำกัดคือ
โดเมนของงานเป็นการจัดสรรทรัพยากรแบบแบ่งส่วนเครือข่ายในระบบเซลลูลาร์ 5G มิใช่การจัดสรรช่องสัญญาณในเครือข่าย 
Wi-Fi Mesh และยังไม่ได้ระบุเทคนิคจัดการความไม่เสถียรของกลไกความสนใจในช่วงต้นของการฝึกสอน [15] 
2.2.9  GA-Net:  MARL for 6G in-X Subnetworks 
    งานวิจัยนี้เป็นงานที่มีความใกล้เคียงกับโดเมนของโครงงานนี้มากที่สุด โดยมุ่งแก้ปัญหาการจัดสรรช่องสัญญาณ

รวมถึงรุ่นที่ตัดกลไกความสนใจของตนเองออก โดยรายงานผลในรูปแบบกราฟมิได้ระบุเป็นค่าร้อยละเดี่ยว จุดที่งานนี้เป็น
แบบอย่างสำคัญคือการประเมินผลด้วยการศึกษาแบบตัดองค์ประกอบภายในสภาพแวดล้อมเดียวกันของตนเอง แทนการนำ

4.1.1  แบบจำลองเครือข่ายและช่องสัญญาณ 
เครือข่ายมี n โหนด (ค่าเริ่มต้น 20) วางแบบสุ่มในพื้นที่สี่เหลี่ยมด้าน 30√n เมตร และสุ่มใหม่จนกราฟลิงก์เชื่อมถึงกัน

ช่องเดียวกันและอยู่ในระยะรบกวนกันแบ่ง airtime ตามจำนวนลิงก์ที่ใช้งานพร้อมกัน 
4.1.2  ทราฟฟิกและต้นทุนการสลับ

ละโหนดเป็นสาย Markov แบบ on/off ที่คงสถานะด้วยความน่าจะเป็น 0.9 ต่อขั้น ขณะ on สุ่มอัตราจากการแจกแจงเอ็กซ์
