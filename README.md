# Dynamic Channel Assignment for Wi-Fi Mesh Networks Using Multi-Agent Reinforcement Learning

EGAT-MAPPO: edge-aware graph attention + MAPPO for joint channel and parent selection in Wi-Fi mesh networks, with hysteresis (margin 2). Evaluated in a flow-level simulator calibrated to ns-3.47 (802.11ax) and confirmed in ns-3.
